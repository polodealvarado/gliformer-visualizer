Interactive 3D walkthrough of GLiFormer Large v1: 24 Transformer layers, entities, classification, joint relations, nested structures, embeddings and document geometry.

This static edition plays actual recorded model runs. For custom text, schemas and document uploads, run the Python server from the [source repository](https://github.com/polodealvarado/gliformer-visualizer).

The document image is a visual reference: this checkpoint consumes text and word-box coordinates, without a pixel encoder.
